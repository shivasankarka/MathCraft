# Reference material (read-only)

Snapshots (2026-11-07) of the ArtCraft team's rules, taken so MathCraft follows them and can later merge into the
ArtCraft suite. Sources: github.com/storytold/craft-anything (v0.4.0, MIT OR Apache-2.0) and github.com/storytold/figcraft (Apache-2.0).

- `craft-anything/`: docs, rules, `deny.toml`, `xtask` (layering/secret checks), `AGENTS.md`, `CLAUDE.md`, `docs/`. Source crates/apps are omitted.
- `figcraft/`: `AGENTS.md` (contains the shared "house rules" block), `ROADMAP.md`, lint/format configs.

Rules for us: read these, follow the rules, do **not copy their code or assets** (their AGENTS.md: original work only).
Do not edit files here; refresh by re-copying from upstream.
